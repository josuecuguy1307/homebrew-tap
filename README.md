# Aleph Homebrew tap

Install the current Aleph macOS release with:

```sh
brew install --cask josuecuguy1307/tap/aleph
```

The cask installs the Apple-silicon (arm64) `Aleph.app` in `/Applications`.
Aleph 0.1.2 is ad-hoc signed and not notarized; read the cask caveat before
opening it for the first time. The manual installer and release notes are at
<https://github.com/josuecuguy1307/Aleph/releases/tag/v0.1.2>.
